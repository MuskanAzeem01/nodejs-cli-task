# Node.js CLI Task

A simple command-line tool built with Node.js that accepts a task title as a command-line argument and prints it to the terminal.

## Features

- Accepts a task title through command-line arguments.
- Prints the provided title to the terminal.
- Uses Node.js and JavaScript.

## Requirements

- Node.js installed on your computer.

## How to Run

1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Run the following command:

```bash
node app.js "Learn JavaScript"
```

## Example Output

```text
Learn JavaScript
```

## Technologies Used

- JavaScript
- Node.js
